# Name swap: stories forced to start with a name

Each story's first word was fixed to the name (prompt: "Write a short story."), so the name comes before any setting exists; the model then wrote freely. If a name carries its archetype, its markers should show up far more often than for plain names (David, Sarah, Thomas, Mary).
